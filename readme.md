**ЛР 1**
Требуется разработать дизайн трех страниц приложения в figma, повторив при этом основную стилистику уже существующего популярного ресурса (3 цвета с точными кодами, hoover, форму карточек), связанного с вашей темой. Данные по теме также нужно искать реальные.

Создание базового интерфейса, состоящего из трех страниц. Дизайн должен быть выполнен в портретном режиме как Vibes (для мобильных телефонов). Снизу на всех страницах располагается панель вкладок с тремя пунктами навигации для трех соответствующих страниц: лента, добавление, плитка карточек.

**План**
1. Дизайн в Figma
2. Реализация бэкенда
3. Настройка Minio
4. Разработка шаблонов
5. Маршрутизация и контроллеры (3 GET-запроса)
6. Тестирование и отладка
